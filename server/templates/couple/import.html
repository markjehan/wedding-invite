A heading row, then one guest per row. Name is the only column it must have. Sinhala name, Phone, Seats, Side (bride or groom) and Notes are used when they are there, in any order and under most names you would give them. Other columns are ignored.

Someone already on the list, with the same number or else the same name, is updated rather than added twice, and an empty cell never wipes out what is already there. So the same sheet can be brought in again after you change it.
